# Halliday-Leonard General Contractors

Portfolio website for Halliday-Leonard General Contractors — custom homes,
developments, and joint ventures in the Ocean City, NJ area.

## Tech stack

- Vite
- React + TypeScript
- Tailwind CSS
- shadcn/ui

## Local development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
